# Методы SDK

> **Пункт 1.19 Требований к игре:** 
>
> SDK Яндекс Игр инициализируется и используется в соответствии с документацией:
>
> 1. SDK инициализируется строго так, как указано на странице [Подключение и использование](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about).
> 2. В момент, когда пользователь может приступить к игре, вызывается метод `LoadingAPI.ready()` из [Game Ready](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events#gameready).
> 3. Если в игре есть разметка геймплея, моменты вызова методов `GameplayAPI.start()` и `GameplayAPI.stop()` соответствуют описанным в разделе [Геймплей](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events#gameplay).
> 4. Если в игре используются методы `ysdk.on()` и `ysdk.off()` для отслеживания событий `game_api_pause` и `game_api_resume`, логика их обработки соответствует описанной в разделе [Пауза и возобновление игры](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events#pause-resume).

## Инициализация SDK

**1.19.1.** SDK инициализируется строго так, как указано на странице [Подключение и использование](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about). Чтобы требование считалось выполненным, должен использоваться актуальный лоадер.

### Проверка актуальности лоадера

1. Запустите игру с debug-панелью.

   Через Консоль разработчика

   Через адресную строку

   1. Откройте [Консоль Яндекс Игр](https://games.yandex.ru/console).
   2. Выберите нужную игру.
   3. В левом верхнем углу нажмите **Открыть с debug-панелью**.

   1. Откройте нужную игру.
   2. Добавьте параметр `debug-mode=16` в конец адресной строки браузера.

      Пример ссылки: `https://yandex.ru/games/app/XXXX?debug-mode=16`, где `XXXX` — уникальный идентификатор игры.
2. На debug-панели слева от индикатора Game Ready найдите две буквы:

   - `IF` (init false) — игра поддерживает старый лоадер. При наведении указателя на `IF` появится надпись *Is loader: false*.
   - `IT` (init true) — игра поддерживает новый лоадер. При наведении указателя на `IT` появится надпись *Is loader: true*.

## Game Ready

**1.19.2.** Когда пользователь уже может начать игру, вызовите метод `LoadingAPI.ready()` из [Game Ready](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events#gameready).

Чтобы требование считалось выполненным, метод `LoadingAPI.ready()` должен вызываться в [корректный момент](https://yandex.ru/dev/games/doc/ru/requirements/1/19#gameready-correct).

### Загрузочный экран

Во время загрузки игры платформа Яндекс Игры вначале показывает свой загрузочный экран — пульсирующую иконку игры и надпись «Загрузка». Его можно скрыть вручную, если нажать на экран.

Как выглядит загрузочный экран Яндекс Игр

![Загрузочный экран Яндекс Игр: пульсирующая иконка игры и надпись «Загрузка»](https://cdn-viewer.diplodoc.com/docs-assets/dev-games/rev/r21993288/ru/_images/requirements/1-19-sdk-methods/gra/yandex-games-loading.webp)

### Подготовка

1. Запустите игру с debug-панелью.

   Через Консоль разработчика

   Через адресную строку

   1. Откройте [Консоль Яндекс Игр](https://games.yandex.ru/console).
   2. Выберите нужную игру.
   3. В левом верхнем углу нажмите **Открыть с debug-панелью**.

   1. Откройте нужную игру.
   2. Добавьте параметр `debug-mode=16` в конец адресной строки браузера.

      Пример ссылки: `https://yandex.ru/games/app/XXXX?debug-mode=16`, где `XXXX` — уникальный идентификатор игры.
2. На debug-панели найдите индикатор Game Ready .

### Логика проверки Game Ready

1. Проверьте, что фиолетовый индикатор  сменился на зеленый  в течение 90 секунд.
2. Перезагрузите игру.
3. Повторно проверьте, в какой момент индикатор меняет цвет.

Модерация проверяет, что:

- индикатор меняет цвет, когда игра становится доступна;
- и загрузочный экран не пропускается кликом.

> **Примечание:** 
>
> Чтобы игра прошла модерацию, Game Ready должен работать корректно: вызов `LoadingAPI.ready()` нужно привязать к реальной готовности игры, а не к конкретному моменту времени.

### Game Ready подключен и работает корректно

Фиолетовый индикатор  сменился на зеленый , когда:

- Начинается [взаимодействие с игрой](https://yandex.ru/dev/games/doc/ru/requirements/1/19#gameready-correct-interaction):
  - Становится доступно управление (в том числе мини-игрой, пока продолжается загрузка).
  - Открывается меню или появляется надпись «Нажмите, чтобы начать».
  - Начинается обратный отсчет.
- Появляется [всплывающее окно](https://yandex.ru/dev/games/doc/ru/requirements/1/19#gameready-correct-pop-up) (например, с политикой конфиденциальности, лицензионным соглашением, предложением авторизоваться или ежедневным бонусом).
- Начинается [неинтерактивный элемент](https://yandex.ru/dev/games/doc/ru/requirements/1/19#gameready-correct-not-interaction) игры (кат-сцена, диалог, стартовая анимация и т. д.).
- Становятся доступны [настройки](https://yandex.ru/dev/games/doc/ru/requirements/1/19#gameready-correct-settings) (графики, управления и т. д.), создание или выбор персонажа, карты или уровня.

## Разметка геймплея

**1.19.3.** Методы `GameplayAPI.start()` и `GameplayAPI.stop()` позволяют размечать начало и остановку игрового процесса. Если они используются в игре, то моменты отправки событий строго соответствуют описанным в разделе [Геймплей](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events#gameplay).

### Подготовка

1. Запустите игру с [debug-панелью](https://yandex.ru/dev/games/doc/ru/console/debug-panel).

   Через Консоль разработчика

   Через адресную строку

   1. Откройте [Консоль Яндекс Игр](https://games.yandex.ru/console).
   2. Выберите нужную игру.
   3. В левом верхнем углу нажмите **Открыть с debug-панелью**.

   1. Откройте нужную игру.
   2. Добавьте параметр `debug-mode=16` в конец адресной строки браузера.

      Пример ссылки: `https://yandex.ru/games/app/XXXX?debug-mode=16`, где `XXXX` — уникальный идентификатор игры.
2. На debug-панели найдите кнопку геймпада 🎮.

### Проверка разметки геймплея

Отслеживайте состояние индикатора геймплея в зависимости от действий:

- Когда игрок начинает игровой процесс или возобновляет его после паузы, должен быть вызван метод `GameplayAPI.start()`. Индикатор геймплея должен стать зеленым  — геймплей в процессе.
- Когда игрок завершает игровой процесс или приостанавливает его, должен быть вызван метод `GameplayAPI.stop()`. Индикатор геймплея должен стать красным  — геймплей на паузе.

Сценарии, которые модерация учитывает при проверке:

- Запуск и завершение уровня.
- Открытие и закрытие игрового меню.
- Открытие и закрытие меню покупок.
- Запуск и закрытие рекламы.
- Потеря фокуса с игры и возвращение в игру (переход на другую вкладку браузера или в другое окно).

> **Совет:** 
>
> Чтобы узнать, где находится фокус (на игре или на другом окне), отслеживайте [события](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events#pause-resume) `game_api_resume` и `game_api_pause`.

### Геймплей размечен корректно

Цвет индикатора меняется в зависимости от сценария.

|  |  |
| --- | --- |
| **Игра** | **Комментарий** |
| Видео выбора и запуска уровня: при появлении уровня индикатор геймплея (иконка геймпада) становится зеленым. | В момент запуска нового уровня индикатор зеленый. |
| Видео геймплея: при завершении уровня индикатор геймплея (иконка геймпада) из зеленого становится красным. | Уровень окончен, индикатор стал красным. |
| Видео геймплея: во время прохождения уровня индикатор геймплея (иконка геймпада) зеленый, при открытии меню он становится красным, после выхода из меню снова становится зеленым. | При переходе в меню и после возвращения в игровой процесс индикатор меняется. |
| Видео геймплея: во время прохождения уровня индикатор геймплея (иконка геймпада) зеленый, при открытии меню он становится красным, после выхода из меню снова становится зеленым. | При переходе в меню и после возвращения в игровой процесс индикатор меняется. |
| Видео геймплея: при переходе из игры в магазин внутриигровых покупок индикатор геймплея (иконка геймпада) из зеленого становится красным. После возвращения в игру индикатор становится зеленым. | При переходе в меню покупок и после возвращения в игровой процесс индикатор меняется. |
| Видео геймплея: при включении рекламы индикатор геймплея (иконка геймпада) из зеленого становится красным. После возвращения в игру индикатор становится зеленым. | Реклама закрылась, цвет индикатора сменился с красного на зеленый. |
| Видео геймплея: во время игры индикатор геймплея (иконка геймпада) зеленый. При открытии другой программы (Проводник) индикатор становится красным. После обратного переключения на вкладку с игрой в браузере индикатор становится зеленым. | При смещении фокуса с вкладки браузера на окно другой программы и после возвращения в игровой процесс цвет индикатора меняется. |

### Геймплей размечен некорректно

Цвет индикатора не меняется в зависимости от сценария.

|  |  |
| --- | --- |
| **Игра** | **Комментарий** |

| Видео геймплея: при включении рекламы индикатор геймплея (иконка геймпада) из зеленого становится красным. После возвращения в игру индикатор остается красным. | Реклама закрылась, цвет индикатора не сменился с красного на зеленый. |
