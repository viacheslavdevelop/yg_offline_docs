# Системный плеер

> **Пункты 1.6.1.6 и 1.6.2.5 Требований к игре:** 
>
> В любых браузерах не отображается системный плеер, вызываемый игрой.

Системный плеер браузера позволяет управлять звуком и видео. Для проверки игры модерация запускает ее на [мобильных устройствах](https://yandex.ru/dev/games/doc/ru/requirements/1/6#mobile) и [десктопе](https://yandex.ru/dev/games/doc/ru/requirements/1/6#desktop) (для проверки на компьютере убедитесь, что [плеер включен](https://yandex.ru/dev/games/doc/ru/requirements/1/6#enable-player)).

## Отключение системного плеера

Системный плеер появляется, когда браузер фиксирует воспроизведение через HTML-элементы `<audio>` или `<video>`. Чтобы этого избежать, используйте Web Audio API — он работает напрямую с аудиоконтекстом и не регистрирует медиасессию в браузере.

Типовой сценарий воспроизведения звука через Web Audio API:

1. Создайте аудиоконтекст: `const ctx = new AudioContext()`.
2. Загрузите аудиофайл через `fetch()` и декодируйте его с помощью [ctx.decodeAudioData()](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData).
3. Создайте источник звука — `AudioBufferSourceNode` — и подключите его к выходу контекста: `source.connect(ctx.destination)`.
4. Запустите воспроизведение: `source.start()`.

Подробнее о Web Audio API см. в [документации MDN](https://developer.mozilla.org/ru/docs/Web/API/Web_Audio_API).

## Проверка на мобильных

Запустите игру. Затем проведите вниз по экрану, чтобы открыть панель уведомлений. Убедитесь, что на ней:

- Плеера нет.
- Плеер есть, но он вызван звуком из другой вкладки или приложения.

## Проверка на десктопе

### Включение плеера

1. Включите системный плеер в настройках браузера.

   Включить плеер в Яндекс Браузере

   Чтобы включить системный плеер в Яндекс Браузере, в верхнем правом углу выберите  → **Настройки** → **Интерфейс** → **Общее** и включите опцию **Показывать на панели инструментов кнопку управления музыкой и видео**.

   Подробнее о плеере читайте в [Cправке Браузера](https://yandex.ru/support/browser/ru/working-with-files/audio).
2. Убедитесь, что плеер работает. Для этого в браузере включите видео или музыку, например [видеоурок по Unity](https://yandex.ru/dev/games/doc/ru/sdk/unity/advertisement).

Если системный плеер настроен правильно, то в правом верхнем углу браузера появится соответствующий значок:

- Google Chrome —
- Яндекс Браузер —

> **Примечание:** 
>
> Если в Яндекс Браузере у вас включена боковая панель, значок может находиться на ней.

### Проверка

Если плеер уже [включен](https://yandex.ru/dev/games/doc/ru/requirements/1/6#enable-player), откройте игру и убедитесь, что:

- Плеера нет.
- Плеер есть, но он вызван звуком из другой вкладки или приложения (чтобы проверить это, нажмите на значок плеера).
