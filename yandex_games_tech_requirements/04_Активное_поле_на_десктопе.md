# Активное поле на десктопе

> **Пункт 1.6.2.1 Требований к игре:** 
>
> Для десктопных устройств активное поле растягивается по вертикали или горизонтали до края доступной области (без учета стики-баннеров).

Активное поле — основная интерактивная область игры на экране. В ней игрок взаимодействует с игровым процессом и интерфейсом. Для комфортной игры активное поле должно максимально масштабироваться под доступное пространство экрана без учета стики-баннеров.

Основные критерии:

- Достаточно растянуть поле хотя бы по одной оси: горизонтали или вертикали.
- Если поле растянуто не полностью, цветной фон (не черный и не белый) также засчитывается.
- Небольшие полосы допускаются: необязательно прижимать игровые элементы вплотную к краю экрана.

## Допустимые примеры

Модерацию пройдут игры, в которых активное поле растянуто хотя бы по одной оси, или игры с цветным (не черным и не белым) фоном вокруг нерастянутого поля. Небольшие полосы допустимы.

|  |  |
| --- | --- |
| **Скриншот** | **Комментарий** |
| Скриншот игры: активное поле растянуто по вертикали до краев экрана. | ✅ Активное поле растянуто по вертикали — требование выполнено. |
| Скриншот игры: активное поле не растянуто полностью по вертикали и горизонтали, но фон вокруг него залит голубым цветом. | ✅ Активное поле растянуто не полностью, но в игре используется цветной фон (не черный и не белый), поэтому требование также считается выполненным. |
| Скриншот игры: активное поле растянуто по вертикали почти до конца экрана, снизу остается небольшая черная полоса. | ✅ Снизу экрана осталась небольшая черная область, что допустимо. |

## Недопустимые примеры

Не пройдут модерацию или будут сняты с публикации игры, в которых активное поле не растянуто ни по одной оси и при этом фон вокруг него черный или белый.

|  |  |
| --- | --- |
| **Скриншот** | **Причина отказа к публикации** |
| Скриншот игры: активное поле занимает только центральную часть экрана, со всех сторон черные области. | 🚫 Активное поле не растянуто ни по горизонтали, ни по вертикали, а фон вокруг него черный. |
| Скриншот игры: активное поле занимает небольшую часть экрана по центру, со всех сторон черные области. | 🚫 Активное поле не растянуто ни по горизонтали, ни по вертикали, а фон вокруг него черный. |
| Скриншот игры: активное поле прижато к верхней части экрана, в нижней части остается белая область. | 🚫 Активное поле прижато к верхней части экрана, но снизу сохранилась заметная белая область, поэтому поле не считается растянутым по вертикали. |
