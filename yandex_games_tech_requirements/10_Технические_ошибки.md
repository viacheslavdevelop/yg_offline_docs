# Технические ошибки

> **Пункт 1.14 Требований к игре:** 
>
> Игра работает без технических ошибок, зависаний и вылетов как в ходе обычного геймплея, так и при различных действиях: повороте экрана, длительном нажатии, жестах, сворачивании браузера, показе рекламы, переходах по истории браузера и других.

Игра должна работать без технических сбоев — при любых действиях пользователя и в разных условиях:

- Корректно [загружаться](https://yandex.ru/dev/games/doc/ru/requirements/1/14#loading).
- Не [зависать](https://yandex.ru/dev/games/doc/ru/requirements/1/14#lags).
- Не содержать [технических надписей](https://yandex.ru/dev/games/doc/ru/requirements/1/14#text).
- Не вызывать [ошибок](https://yandex.ru/dev/games/doc/ru/requirements/1/14#errors) и браузерных уведомлений.

## Загрузка игры

|  |  |
| --- | --- |
| **Игра** | **Комментарий** |
| Видео загрузки игры: после экрана с иконкой игры и надписью «Загрузка» возникает реклама, а затем экран становится полностью черным. | Игра не загружается: видна только иконка игры. |
| Видео загрузки игры: экран полностью черный на протяжении всего видео. | Игра не загружается: виден только черный экран. |
| Скриншот загрузки игры: в правой части экрана открыта консоль Devtools. В ней есть несколько строк, выделенных красным: они описывают ошибку и трейс вызовов, которые к ней привели. | Игра не загружается, в консоли браузера возникает ошибка. |
| Видео загрузки игры: после загрузки появляется черный экран. После нескольких секунд по экрану кликают, и возникает логотип игры. | Игра начинает загружаться только после клика по экрану. |
| Видео загрузки игры: под иконкой игры крутится кружок. После нескольких секунд страницу перезагружают, на месте кружка появляется быстро заполняющаяся шкала загрузки, а затем возникает игровое поле. | Чтобы игра загрузилась, нужно перезагрузить страницу. |
| Видео загрузки игры: во время загрузки страницу с игрой перезагружают и через несколько секунд появляется ошибка «На странице «...» повторно возникла проблема». | Игра вылетает во время загрузки. |
| Скриншот ошибки: «к сожалению, страница не может быть загружена». | Страница игры не загружается на iOS. |

| Видео геймплея: при изменении размера окна практически все игровое поле перекрывает черный прямоугольник. | После выхода из полноэкранного режима игра зависает, отображается черный экран. |
